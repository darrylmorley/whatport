A sharper menu bar icon

One fix: the menu bar icon now renders crisp on Retina displays.

## Fixed

- **The menu bar icon is no longer blurry on Retina displays.** The app was loading the standard-resolution icon file and letting macOS stretch it, while the sharp 2x version sat unused in the app bundle. Both are now loaded properly, so the icon is as crisp as the system's own. Thanks to Linkst for the report (#6).

## Install

Download below, unzip, and drag WhatPort.app to Applications, or:

```
brew upgrade --cask whatport
```

The app is signed and notarised by Apple.
