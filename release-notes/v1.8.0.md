See everything behind your dock

Ports with a hub or dock used to show one device, and usually the least interesting one. WhatPort now knows the whole tree.

## New

- **Device tree per port (Pro).** The port detail now shows every USB device behind the port: what's plugged into your dock, what's behind the hub inside it, and which hub or dock each device arrived through. Hubs are tucked behind a toggle by default, because what you care about is the drive, not the plumbing it hangs off.

- **The port row names the real device.** Plug in a dock and the row used to say "USB2.0 Hub", because the hub is the first thing macOS sees. Now it names the first actual device behind the port, with a "+N more" count on the detail card when there are others (Pro shows them all in the tree).

## Fixed

- **Devices can no longer be pinned to the wrong port.** On Macs that skip a physical port number, a device could be filed under a port that doesn't exist, or worse, someone else's card. Attribution now uses the same registry join the port statistics use, and when WhatPort genuinely can't tell, it says nothing rather than guessing.

- **480 Mbps no longer masquerades as your connection speed.** A Thunderbolt link also enumerates a small USB2 endpoint, and its genuine 480 Mbps sat one card above "40 Gbps" looking like a downgrade. The device card now says whose speed that is.

## Install

Download below, unzip, and drag WhatPort.app to Applications, or:

```
brew upgrade --cask whatport
```

The app is signed and notarised by Apple.
