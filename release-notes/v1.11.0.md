Numbers now follow your region, and a USB-C port that some Macs were missing is back.

## New

- **Numbers follow your region.** Watts, percentages and other figures now use your Mac's own decimal separator, so a comma-decimal region sees "8,9 W" rather than "8.9 W".

## Fixed

- **A missing USB-C port.** On some Macs, one port's controller publishes no identifier, and WhatPort used to leave that port out. It now shows it, with its power.

## Under the hood

- WhatPort no longer keeps an unused settings window behind the scenes. Newer versions of Apple's developer tools would have opened it, blank, every time the app started.

## Install

Download below, unzip, and drag WhatPort.app to Applications, or:

```
brew upgrade --cask whatport
```

The app is signed and notarised by Apple.
